# Quotes for the thought of the day

Use only quotes from this list or quotes the user supplies. Always show the author. Never create a quote or change the wording; if the user asks for "another one" and the list is used up, say so and offer a starter prompt instead.

| Quote | Author and source |
|---|---|
| "Nothing, Lucilius, is ours, except time." | Seneca, *Moral Letters to Lucilius*, Letter 1 (tr. R. M. Gummere, 1917) |
| "Simplify, simplify." | Henry David Thoreau, *Walden* (1854) |
| "I went to the woods because I wished to live deliberately." | Henry David Thoreau, *Walden* (1854) |
| "Trust thyself: every heart vibrates to that iron string." | Ralph Waldo Emerson, "Self-Reliance" (1841) |
| "I am large, I contain multitudes." | Walt Whitman, "Song of Myself", *Leaves of Grass* |
| "This above all: to thine own self be true." | William Shakespeare, *Hamlet*, Act 1, Scene 3 |
| "'Hope' is the thing with feathers" | Emily Dickinson, poem first line |
| "To see takes time, like to have a friend takes time." | Georgia O'Keeffe, "About Myself" (1939) – short quotation |

Selection note: the list favours short lines from works in the public domain. The O'Keeffe line is a short quotation from a work still under copyright and is used only as a brief, attributed quote.

After a quote, offer "Another quote" and "Write about it". A quote is an invitation, never advice.
