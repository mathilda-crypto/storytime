# Application kit (Career and freelance)

## Achievement bank

Saved at `[journal folder]/career/achievement-bank.md`. Each item comes from an entry and keeps a link to it:

```markdown
- Led the supplier change – source: entries/2026-11-15-interview.md – result: [THE RESULT] – people: [WHO WAS INVOLVED]
```

Add an item only when the user confirms it ("Add to achievement bank"). Unknown details stay in brackets.

## One application = one folder

`[journal folder]/career/applications/[role name]/` holds the job ad, the role description, drafts and `application-plan.md`.

## Connected sources

| Source | How it arrives |
|---|---|
| Job ad | PDF, DOCX, image or text the user saved in the application folder |
| Role description | Pasted from an email, or a saved file |
| LinkedIn profile | Pasted text, or the PDF export the user saved |
| Achievement bank | The file above |

## Match

For each requirement written in the ad or role description, show the user's evidence with its source entry, or "Gap". For a gap, ask: add a real example, or plan how to talk about it. Never fill a gap with an invented example.

## Preparation plan (default steps)

1. Tailor the CV to the ad.
2. Draft the cover letter.
3. Update LinkedIn headline and About.
4. Practise three interview stories (an experiment with a review date).
5. Prepare questions to ask them.
6. Apply by [DATE] – the user supplies the date.

## Drafts

Built only from achievements the user ticks. Every bracketed gap stays visible until the user fills it. Storytime never signs in to LinkedIn or job sites and never sends an application.
