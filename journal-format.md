# Journal format

## Folder layout

All inside the journal folder the user names:

```
entries/                 dated journal entries (searched by Talk with my diary)
vault/                   private inner-life entries; never read unless the user asks in that conversation
programme/storytime-programme.md
settings/storytime-settings.md
career/achievement-bank.md
career/applications/[role name]/
drafts/                  stories, plans and other drafts
```

## Entry file

File name: `[written date YYYY-MM-DD]-[short-title].md`. Content:

```markdown
# Interview reflection
- Written: 2026-11-15
- Happened: 2026-11-14
- Journey: Career and freelance
- Privacy: private
- Source: typed | voice note [exact audio path] | handwriting photo [exact image path]
- Mode: Listen

[The entry text exactly as the user wrote or confirmed it.]

## Reflection (optional, only if the user chose to save it)
- Recorded: …
- One possible reading: …
```

Rules:

- **Written** is the date the entry was saved; **Happened** is the date the user gave for the event. If the user gave no event date, leave Happened out – never guess it.
- The user's own text is stored exactly as confirmed. Reflections are stored only when the user asks, and keep the "Recorded" / "One possible reading" labels.
- Corrections: when the user corrects a fact, save a new entry or update the same file with the user's approval, and add `- Corrected: [date]`.

```markdown
# Storytime settings

```
